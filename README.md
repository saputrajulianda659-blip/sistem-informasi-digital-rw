
# Sistem Informasi Pelayanan Digital RW

Sistem Informasi Pelayanan Digital RW merupakan aplikasi berbasis web yang dikembangkan untuk membantu meningkatkan pelayanan administrasi dan komunikasi antara pengurus RW dengan warga.

## Fitur Sistem
- Pelayanan administrasi surat.
- Pengaduan warga.
- Informasi dan pengumuman.
- Pengelolaan kas dan iuran.
- AI Assistant.
- Pengelolaan hak akses pengguna.

## Teknologi
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Instalasi
1. Clone repository ini.
2. Simpan folder proyek di direktori `www` Laragon.
3. Jalankan Apache dan MySQL.
4. Konfigurasikan database dan environment sesuai kebutuhan.
5. Buka aplikasi melalui browser.
